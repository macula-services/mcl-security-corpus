## One-page summary

**Network security monitoring (NSM)** is the collection and analysis
of network data to detect and respond to intrusions. The data comes in
five types — full content, session, transaction, statistical, and
alert — each a different trade of detail against volume. NSM is the
layer that catches what prevention missed: prevention fails eventually,
detection is the assumption that it did.
