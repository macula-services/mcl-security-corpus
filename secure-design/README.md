## One-page summary

Secure design is asking, unironically, **"what could possibly go
wrong?"** — then working the answer systematically: model the system,
name the assets, find the attack surfaces and trust boundaries,
enumerate threats (STRIDE), rank them, mitigate the top of the list,
and test the mitigations. The four questions — what are we working on,
what can go wrong, what are we doing about it, did we do a good job —
are the whole discipline in one breath.
